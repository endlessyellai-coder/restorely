Restorely privacy policy

Last updated: 23 November 2026

Restorely is a Chrome extension that saves and restores browser tab sessions on your computer. This page explains what the extension does with data. It is written for the Chrome Web Store and for anyone using the extension.

No data leaves your browser

Restorely does not send your tabs, sessions, backups, settings, or “notify me” interest marks to a server. It has no account, no analytics, no advertising, and no third-party tracking. There is no network request made by the extension for telemetry or sync in this version.

The only files that leave your computer are ones you export yourself, when you choose to download a JSON backup or import a file you already have.

What is stored, and where

Restorely stores the following in Chrome’s local extension storage on the profile you are using:

  • Named sessions you save, including tab addresses, titles, pinned state, and tab group name, colour, and collapsed state where the browser exposes them.
  • Automatic dated backups of the windows that were open, kept as a rolling history.
  • A last-known snapshot used to recover the previous browser state after Chrome starts.
  • Your settings, such as backup frequency and how many backups to keep.
  • A local count if you click “Sync across devices: notify me when ready”. That click is not transmitted anywhere.

This data stays in your Chrome profile until you delete a session or backup, clear the extension’s data, or uninstall Restorely.

Permissions

Restorely asks only for the permissions it needs to do this work:

  • tabs — to read the open tabs so they can be saved, and to reopen them when you restore a session or backup.
  • tabGroups — to preserve and restore tab group names, colours, and collapsed state.
  • storage — to save sessions, backups, and settings on this computer.
  • unlimitedStorage — so a history of backups is not cut short by Chrome’s default 10 MB local storage limit.
  • alarms — to take periodic automatic snapshots, including after the extension’s background worker has been asleep.

Restorely does not request access to every website, does not read the content of pages, and does not run a script on the sites you visit.

What Restorely cannot restore

Some addresses, such as certain chrome:// or file:// pages, cannot be reopened by an extension. Those tabs may be stored in a snapshot and skipped on restore, with a visible note where possible.

Incognito windows are only visible if you choose to allow the extension in incognito. Even then, restored windows are opened as ordinary windows.

Children

Restorely is a general-purpose browser tool. It does not knowingly collect personal information from anyone, including children, because it does not collect personal information at all.

Changes

If a later version of Restorely introduces optional sync or any feature that would send data off the device, this policy will be updated first, and that feature will be off unless you opt in.

Contact

Questions about this policy can be sent to the publisher listed on the Restorely Chrome Web Store page once the extension is published. Until then, use the support contact supplied with the listing or the GitHub repository that hosts this page.

Restorely is a local browser extension. This policy describes version 0.2.0.
